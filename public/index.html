SUPERVISION POLICY

如何监督工作

  1. 明确目标任务必须填写目标与验收条件
  2. 人工下发选定空闲实例，不抢占已有任务
  3. 规则观察查看会话异常与活动记录
  4. 证据验收提交结果，由你确认完成

当前不自动重试、不自动批准命令、不自动部署。无输出不等于卡死；AI 自述完成不等于验收通过。规则依据最近同步记录，自动更新不等于自动执行。

SSH DISCOVERY

添加 SSH 机器

只支持 SSH Key / ssh-agent 免密登录。添加后会检测 Claude、Codex、Gemini 和 tmux；不会安装任何程序。

FRP SERVER

自动部署云端 frps

选择一台已通过 SSH 接入的公网 Linux 机器。部署需要 root 或免密 sudo；会安装 frps、写入 systemd 服务并开启 TLS。

FRP RELAY

开放局域网机器到公网

使用 FRP STCP，不暴露 SSH 端口。Hub 会自动部署远端 frpc，并在本地启动 visitor；后续 SSH 会改走 127.0.0.1:22xxx。
