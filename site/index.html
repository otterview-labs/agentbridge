agentBridge Android 应用

在手机上连接自己的机器，查看并回复上面运行的 Claude Code / Codex 会话。

下载 APK

最新版 · Android 7.0 及以上 · 约 300 KB · Apache-2.0

用法

应用可以直接 SSH 到你的机器，列出上面正在跑的 Claude Code / Codex 会话，看输出、发输入。被连的机器不需要装 agentBridge。

也可以连你已经跑着的 agentBridge 服务，工作室的对话、记忆、日报跟网页端是同一份；断网时退回本机记录。

语音输入优先用手机自带的识别。手机没有识别器时，短录音会发到 agentBridge 服务用 whisper-cli 转写，转完即删，不经过第三方。

安装

  1. 下载 agentbridge.apk。
  2. 系统会拦一次，在设置里允许安装未知来源应用。
  3. 打开应用，用「发现机器」扫描局域网，或者手动填 SSH 地址和账号。

APK 由本仓库的 CI 从 android-v* 标签构建，用固定的发布密钥签名。构建日志在 Actions 里，也可以对照源码自行构建。
