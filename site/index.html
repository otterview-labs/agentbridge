P agentBridge SELF-HOSTED AGENT CONSOLE

把手机变成一个终端遥控器

agentBridge 是一个自托管的 AI 编程助手控制台。Android 应用可以直连你自己的远程机器， 发现并回复上面跑着的 Claude Code / Codex 会话 —— 那些机器不需要安装本项目。

下载 Android 应用
版本 最新版 要求 Android 7.0 及以上 约 300 KB 许可 Apache-2.0

首次安装需要允许「安装未知来源应用」。这个 APK 由本仓库的 CI 构建并用固定的发布密钥签名， 源码、构建脚本和签名流程都在仓库里，可自行核对或自行构建。

装上之后能做什么

  • 直连远程机器 — 经 SSH 发现机器上的 Claude Code / Codex 会话，查看输出、回复输入；对方机器不需要装 agentBridge。
  • 或者连上 Hub — 如果你已经在跑 agentBridge 服务，手机可以连上去，共用同一套小镇工作室的对话、记忆与日报，断网时退回本机记录。
  • 语音输入 — 手机没有系统识别器时，会把短录音上传到 Hub，用本地 whisper-cli 转写，转写完即删，不发往第三方云。

安装

  1. 点上面的按钮下载 agentbridge.apk。
  2. 在系统提示或「设置 → 应用 → 特殊应用权限」里允许安装未知来源应用。
  3. 打开应用，用「发现机器」扫描局域网，或手动填 SSH 地址、账号与密码 / 私钥。
