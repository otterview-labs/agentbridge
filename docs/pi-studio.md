# Pi 小镇工作室

工作室入口为 `/studio`（或 `/studio.html`）。旧控制台保留在 `/` 和
`/index.html`，两边都有入口，不更改已有任务执行、SSH 和公网部署流程。

## Web 与手机

- Web 使用左右布局，手机浏览器使用底部「管家 / 小镇 / 规划 / 记忆」导航。
- Android 0.5.0 默认打开同一套工作室资源。「控制台」仍可进入原有 SSH、
  待输入和公网管理页，任务可直接跳转原任务详情。
- Android 构建前的 `syncStudioAssets` 自动从 `public/studio.*` 同步资源，
  不要直接修改 Android 中的这三份生成副本。
- Android 未连接 Hub 时只显示本机记录，不能调用 Pi。连接后，Web 和手机
  直接读写同一个 Hub 的对话、记忆和任务规划，不各自维护一份云端副本。
- 在手机「连接与模型」中填写 Hub 根地址和至少 32 位的 API Token，
  点击「测试并连接」。公网必须使用 HTTPS；可信局域网 HTTP 需要明确勾选，
  且不适合公网。电脑的 `127.0.0.1` 不是手机可访问的电脑地址。
- 默认不上传手机任务。勾选「同步本机机器与任务摘要」后，读取共享页面时
  上传白名单字段：机器名、已检测工具、任务标题、状态和记录时间。
  不上传 SSH 密码、私钥、用户名、地址、原始输出或命令行。记录按设备与本机
  ID 区分，旧版本不能覆盖新版本；同一机器从两个来源接入时不会自动合并。
- 本机旧偏好通过「合并本机记忆」明确导入，同一来源重复导入不重复创建，
  已在 Hub 删除的偏好也不会因再次导入而复活。本机原记录不删除。
- 前台空闲时每 30 秒读取共享记录，编辑输入、打开设置或查看历史任务规划时不刷新；
  后台不保持同步。断网会保留上次记录并标注过期，不冒充同步成功或静默退回本机。
- 取消任务同步并保存连接时，删除当前 Hub 的本机任务快照；「仅断开本机」
  只移除本机 Hub 连接，已经上传的快照、对话和记忆保留。
- Web 页面刷新只重新读取已保存记录，不启动 SSH 探测或自动执行命令。
  机器在线状态是最近记录，不是实时连通性承诺。

## Pi 模型配置

Node.js 要求 >= 22.19.0。使用锁定的 `@earendil-works/pi-agent-core` 和
`@earendil-works/pi-ai` 0.86.0，无文件、Shell、SSH 或审批工具。

推荐在「连接与模型 → Pi 模型接入」中设置：

1. 选择 Anthropic、OpenRouter 或 OpenAI 兼容接口。
2. 填写准确模型 ID、API Base URL 和专用 API Key，勾选启用。
3. 可点击「测试连接」确认。它会产生一次模型调用，不发送任务或对话，不自动保存。
4. 点击「保存配置」，立即生效，无需重启。保存配置不等于提供商已验证可用。

Anthropic 和 OpenRouter 的模型 ID 必须在安装的 Pi provider 目录中；
自定义或目录未收录的模型可使用支持 Chat Completions 的 OpenAI 兼容接口，
但不是所有提供商的兼容实现都经过实测。API 地址必须为 HTTPS，
本机模型可使用 `http://localhost` / `127.0.0.1` / `[::1]`。
更换提供商或地址必须重新输入密钥，防止把旧密钥转发给新服务。

模型配置用 AES-256-GCM 加密保存到 SQLite；独立的 `dataDir/pi-model.key`
权限为 0600。备份和恢复需同时包含数据库与密钥文件，不能只备份数据库。
丢失密钥会拒绝解密，不会静默生成替代密钥。加密不能抵御已控制 Hub 主机的攻击者。
所有配置接口要求 Hub 鉴权；密钥不回显，不写入浏览器持久存储。
手机 Hub Token 由 Android Keystore 加密保存，仅原生网络层使用，
不会返回给页面 JavaScript。两种连接均拒绝重定向，避免凭据被转发。

尚未保存页面配置时，也可在 Hub 环境中配置并重启：

```dotenv
ASB_PI_ENABLED=true
ASB_PI_PROVIDER=anthropic
ASB_PI_MODEL=your-model-id
ASB_PI_API_KEY=your-dedicated-api-key
# OpenAI-compatible endpoints require an explicit base URL:
# ASB_PI_PROVIDER=openai-compatible
# ASB_PI_BASE_URL=https://your-provider.example/v1
```

页面保存的配置优先于环境变量。默认关闭，不读取其他 CLI 的 OAuth，也不自动使用环境中的
`ANTHROPIC_API_KEY` 等通用密钥。未配置时对话不可发送；工作记录摘要不是
AI 生成，不会以固定文案冒充模型回复。

启用后，每次用户发送会传递当前问题、最近 20 条对话（每条最多 3000 字）、
用户确认的偏好、最多 100 条任务记录（含截断后的目标、验收证据、今日活动或
会话摘要）及机器状态给配置的提供商。任务规划另行按状态选取最多 34 条，
并只传递每条压缩到 700 字的证据摘要。没有传递
SSH 密码、私钥、原始终端输出、环境变量或命令行。任务标题与用户自己输入的
内容、证据或摘要仍可能包含敏感信息，请在启用前确认数据使用范围。模型有
180 秒超时、1800 输出 token 上限和单轮限制；应用不自动重发失败请求，
也不生成成功记录。Pi 没有执行、审批或自动写记忆工具。

## 记忆与任务规划

- Hub 将确认偏好与对话保存到 SQLite 的 `studio_memories` /
  `studio_messages`，不伪造 CLI 会话。记忆最多 50 条，每条 500 字。
- Android 离线模式记忆保存在应用私有 SharedPreferences；连接模式直接保存到 Hub。
- 只有用户点击「记住」才写入记忆。删除偏好不会删除旧对话里提过的内容。
- Hub 为单个可信用户设计：拥有同一个 API Token 的浏览器共享上下文，
  不是不同用户的数据隔离系统。公网部署应使用 HTTPS 和强 API Token。
- 任务规划由 Pi 分析后输出「整体结论、已验收成果、推进中的工作、
  阻塞风险、明日优先事项、需要你决定」。每个条目要求是一句可执行、
  可验收的话，并说明项目、动作和判断结果。工作记录列表仅在折叠的依据区展示。
- 任务规划按 `Asia/Shanghai` 计算。点击「生成任务规划」才调用模型，
  输入当天近期对话、确认偏好和按状态有界选取的任务证据摘要。
  只允许生成当天报告，历史日期读取已保存的版本，不拿当前状态重建过去。
- 生成结果需通过结构和来源校验；「已验收成果」必须引用当天有
  「人工验收通过」事件且当前为 completed 的 Hub 任务。
  引用不存在的任务或把未验收任务列为完成会拒绝保存。
  这些规则不等于对全部自然语言做了事实证明，用户仍应核对关键结论。
- SSH 会话没有验收记录；空闲、停止、无输出都不能推断为完成。
- 每次成功生成都保存新版本、时间、模型标签和任务来源，不覆盖旧版本。
  模型标签是配置标识，不是对远端真实模型身份的独立证明。
  页面可按日期查看最新版本；接口可读取该日期最近 20 个版本。
  失败保留旧任务规划，不用固定文案冒充 AI 总结。
- 明日事项是管家建议，不会创建、派发或批准任务。没有定时推送任务规划的后台任务。

## 验证

```sh
npm run typecheck
npm test
npm run build
PLAYWRIGHT_MODULE=/path/to/playwright node --test android/tests/studio-ui.test.cjs
cd android
JAVA_HOME=/path/to/jdk21 ./gradlew --offline --no-daemon :app:assembleDebug
```

自动化测试包含模拟 HTTP / Android bridge、数据库重启与加密校验，以及实际
Pi Agent SDK 连接本机模拟 SSE 模型的测试，不等于真实付费模型或公网服务验收。
配置了专用密钥后，仍需使用「测试连接」并完成一次真实对话及任务规划生成验证。
既有 SSH、公网连接与服务生命周期风险不由本轮 UI 更新修复。
